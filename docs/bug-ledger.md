# Bug ledger

Meaningful defects found while building and operating the platform: what was seen, why, the
fix, and what now prevents a regression. "Break" IDs refer to deliberate-break entries in
`scripts/mutations/mutations.mjs` (CI requires the named tests to fail when the break is applied).
